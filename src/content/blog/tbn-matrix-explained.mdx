## 什么是 TBN 矩阵？

**TBN** = **T**angent（切线）+ **B**itangent（副切线）+ **N**ormal（法线）。

这三个向量组成一个 3×3 矩阵，它的作用只有一个：**在切线空间和世界空间之间做坐标变换**。

听起来抽象？下面这个 3D 场景会让你秒懂——拖拽旋转这个平面，观察 T、B、N 三个箭头如何始终"贴"在表面上：

<CoordinateSpaceIntro client:only="react" />

无论表面朝哪个方向，这三个向量始终构成一个**贴合在表面上的局部坐标系**。这就是切线空间的本质。

---

## 为什么需要它？

法线贴图里存的法线是在切线空间下定义的——(0, 0, 1) 永远表示"垂直于表面向外"。这样同一张贴图可以贴在任何朝向的表面上。

但光照计算在世界空间进行。所以我们需要 TBN 矩阵把切线空间的法线"翻译"到世界空间。

---

## 推导第一步：边向量与 UV 的对应

TBN 的计算从一个三角形开始。每个三角形有 3 个顶点，每个顶点有 3D 坐标和 UV 坐标。

下面的场景同时展示了 3D 空间中的三角形（左）和 UV 空间中的映射（右）。两条边向量 E₁、E₂ 连接了这两个空间：

<EdgeVectorDemo client:only="react" />

**关键洞察**：3D 空间中的边向量 E₁ 和 E₂，可以用 UV 空间中的位移来"分解"。这个分解关系就是 TBN 的数学基础。

---

## 推导第二步：边向量 = T 和 B 的线性组合

核心公式很直观：**边向量 = 沿 U 方向走了多少 × T + 沿 V 方向走了多少 × B**

拖动下面的滑块，直观感受这个分解过程：

<DerivationScene client:only="react" />

红色段是 Δu·T（沿切线方向的分量），绿色段是 Δv·B（沿副切线方向的分量），黄色箭头是它们合成的边向量。

**这就是公式的几何含义**：知道了边向量和 UV 差值，就能反推出 T 和 B 的方向。

## 曲面上的 TBN：每个点都不同

在平面上，所有点的 TBN 一样。但在曲面上，每个点都有自己的 TBN 坐标系，它们随着表面法线的变化而旋转。

调节下面的波浪参数，观察 TBN 如何"贴合"在曲面上：

<CurvedSurfaceTBN client:only="react" />

**关键理解**：把幅度调到 0（平面），所有箭头方向一致。增大幅度后，每个点的蓝色箭头（N）始终垂直于局部表面，红色和绿色箭头则沿着表面展开。

## 法线贴图为什么是蓝紫色的？

这是一个经典问题。答案藏在编码公式里：法线方向通过 `color = normal * 0.5 + 0.5` 映射到 RGB。

拖动下面的滑块改变法线方向，实时看到对应的颜色：

<NormalMapColorDemo client:only="react" />

当法线指向 (0, 0, 1)（垂直于表面向外）时，RGB = (128, 128, 255) —— 正是那个标志性的蓝紫色。大部分表面的法线都接近这个方向，所以法线贴图整体呈蓝紫色调。

## 实践中的正交化

由于 UV 映射可能有拉伸，计算出的 T 不一定严格垂直于 N。实践中用 Gram-Schmidt 正交化来修正：

<GramSchmidtDemo client:only="react" />

增大角度让 T 偏离水平面，然后观察正交化如何将 T 投影回垂直于 N 的平面上。对应的 Shader 代码：

```glsl
// Gram-Schmidt 正交化
T = normalize(T - dot(T, N) * N);
B = cross(N, T);
```

---

## Shader 中的两种用法

### 方法一：法线从切线空间 → 世界空间

```glsl
// 片段着色器
vec3 N_tangent = texture(normalMap, uv).rgb * 2.0 - 1.0;
vec3 N_world = normalize(TBN * N_tangent);
float diffuse = max(dot(N_world, lightDir), 0.0);
```

### 方法二：光照向量从世界空间 → 切线空间（更高效）

```glsl
// 顶点着色器（逐顶点，更省）
mat3 TBN_inv = transpose(TBN); // 正交矩阵的逆 = 转置
vec3 lightDir_tangent = TBN_inv * lightDir;

// 片段着色器（直接用切线空间法线）
vec3 N = texture(normalMap, uv).rgb * 2.0 - 1.0;
float diffuse = max(dot(N, lightDir_tangent), 0.0);
```

方法二更高效：矩阵乘法在顶点着色器中逐顶点计算（顶点数远少于片段数），片段着色器只需一次 dot 运算。

## Handedness（手性）

有些模型的 UV 是镜像的，TBN 会变成左手系。通常在顶点属性中存储 `tangent.w = ±1` 来标记：

```glsl
vec3 B = cross(N, T.xyz) * T.w;
```

---

## 总结

TBN 矩阵是连接纹理空间和世界空间的桥梁。它让法线贴图能够在任意朝向的表面上正确工作，是现代实时渲染中法线贴图、视差映射、各向异性高光等技术的数学基础。

核心要点：
- **T** 沿纹理 U 方向，**B** 沿 V 方向，**N** 垂直于表面
- 通过三角形的边向量和 UV 差值反推 T 和 B
- TBN 矩阵将切线空间向量变换到世界空间
- 实践中需要 Gram-Schmidt 正交化和手性处理
