## 这节课在 GAMES101 里到底讲什么？

第 17 课 **Materials and Appearances** 的重点不是“给模型贴一张颜色图”，而是回答一个更物理的问题：

> 光从某个方向打到表面后，材质会把多少能量分配到另一个方向？这种方向分配规律如何决定我们看到的漫反射、高光、金属、玻璃、粗糙表面和拉丝效果？

如果前几节课的路径追踪告诉你：

```text
camera ray 命中表面 -> 采样下一条光线 -> 累积光照贡献
```

那么本节课就在补全最关键的那一问：

```text
命中表面以后，下一条光线应该往哪里走？每个方向应该带走多少能量？
```

渲染方程里，材质对应的核心接口就是 BRDF：

$$
L_o(p, \omega_o)=L_e(p, \omega_o)+\int_\Omega^+ f_r(p, \omega_i, \omega_o)\,L_i(p, \omega_i)\,\cos\theta_i\,d\omega_i
$$

其中最像“材质说明书”的是 $f_r(p, ω_i, ω_o)$。它不是最终颜色，而是 **从入射方向到出射方向的能量分配函数**。

<AppearanceStack3D client:only='react' />

上面的交互故意固定几何，只调材质、微法线和环境光。你会看到：同一个球可以像塑料、陶瓷、金属或玻璃。这说明外观不是单个 RGB 决定的，而是多层因素共同作用。

| 层次 | 它控制什么 | 直观例子 |
|---|---|---|
| Geometry | 形状、宏观法线、曲率、遮挡 | 同样材质放在球和平面上，高光形状完全不同 |
| Micro-geometry | 肉眼看不到的小凹凸、小镜面 | 粗糙金属的高光会变宽、变暗、拖尾 |
| Lighting | 入射光方向、颜色、面积、环境 | 金属没有环境反射会显得死黑 |
| Material | 反射、透射、吸收、散射的规则 | 纸、塑料、镜子、玻璃、皮肤 |
| Camera / Display | 曝光、色调映射、色彩空间 | HDR 高光如何压到屏幕上 |

## 0. 先建立一张“材质地图”

学习材质时最容易迷路，因为术语很多：BRDF、BSDF、Fresnel、NDF、roughness、metallic、anisotropy、measured material……



```text
光线与表面交互
├─ 反射 reflection      -> BRDF
│  ├─ 漫反射 diffuse    -> Lambertian
│  ├─ 光泽 glossy       -> Microfacet
│  └─ 理想镜面 mirror   -> delta distribution
├─ 透射 transmission    -> BTDF
│  └─ 折射 refraction   -> Snell + Fresnel
├─ 反射 + 透射          -> BSDF
├─ 进入内部再出来       -> BSSRDF / subsurface scattering
└─ 自己发光             -> emission / Le
```

这节 GAMES101 的主线是从 **BRDF** 出发，逐步把真实材质的复杂外观解释出来。

## 1. 光撞到表面后，能量去哪了？

一束光到达表面点 $p$ 后，能量一般会分成几份：

$$
E_in = E_reflected + E_transmitted + E_absorbed
$$

也就是：

$$
R + T + A ≤ 1
$$

| 去向 | 名字 | 对应模型 | 例子 |
|---|---|---|---|
| 回到表面同侧 | Reflection | BRDF | 墙面反光、金属高光、镜面反射 |
| 穿过表面 | Transmission | BTDF | 玻璃、水、薄塑料 |
| 留在材料里 | Absorption | 吸收系数 | 黑布吸光、彩色玻璃吸收部分波长 |
| 进入内部多次散射后出来 | Subsurface Scattering | BSSRDF | 皮肤、玉、蜡、牛奶 |
| 材料自己发光 | Emission | $L_e$ | 灯管、屏幕、火焰 |

<BSDFSplitLab3D client:only='react' />

所以：

- **BRDF**：只描述反射半球内的方向分布。
- **BTDF**：描述透射到另一侧的方向分布。
- **BSDF**：把 BRDF 和 BTDF 统一起来。
- **BSSRDF**：进一步允许光在一个位置进入，在另一个位置出来。

GAMES101 第 17 课主要围绕 BRDF 展开，因为它是表面反射外观的核心。

## 2. BRDF 的定义：它不是颜色，是“方向密度”

BRDF 全称是 **Bidirectional Reflectance Distribution Function**，定义为：

$$
f_r(p, ω_i, ω_o) = dL_r(p, ω_o) / dE_i(p, ω_i)
$$

入射微分照度是：

$$
dE_i(p, ω_i) = L_i(p, ω_i) cosθ_i dω_i
$$

把它翻译成人话：

1. 从方向 $ω_i$ 来了一小束光。
2. 这束光在表面点 $p$ 上形成一点点 irradiance。
3. 材质决定其中有多少会被反射到观察方向 $ω_o$。
4. 因为出射方向是按立体角分布的，所以 BRDF 的单位是 $1 / sr$。

| 符号 | 含义 | 直觉 |
|---|---|---|
| $p$ | 表面点 | ray 命中的那个 shading point |
| $n$ | 宏观法线 | 面片或插值后的 normal |
| $ω_i$ | incoming direction | 从表面看向光来的方向 |
| $ω_o$ | outgoing direction | 从表面看向相机或下一段路径的方向 |
| $θ_i$ | 入射方向与法线夹角 | 决定投影项 $cosθ_i$ |
| $dω_i$ | 一个很小的方向范围 | 半球上的一个小方向桶 |
| $f_r$ | BRDF | 方向到方向的反射比例密度 |

### 为什么不能说 BRDF 就是颜色？

因为颜色只是某些方向、某些光照、某个相机曝光下的结果。BRDF 是更底层的规律。

举例：一块白塑料在正面看可能只是白色，但在掠射角会有明显高光；一块金属在阴暗环境下可能发黑，但放到彩色环境中会反射环境颜色。RGB 颜色无法单独解释这些方向相关变化。

更准确地说：

```text
材质参数 + 入射光分布 + 几何法线 + 观察方向 + 相机显示管线 = 最终像素颜色
```

BRDF 只负责其中“材质如何按方向分配光”的部分。

## 3. 物理合理 BRDF 必须满足的约束

渲染里可以设计很多 BRDF，但物理上合理的被动材质至少要满足下面几条。

### 3.1 非负性：不能反射负能量

$$
f_r(p, ω_i, ω_o) ≥ 0
$$

这看似废话，但在拟合材质、用球谐函数或神经网络表示 BRDF 时，真的可能出现负值。负 BRDF 会让渲染结果出现奇怪暗斑或能量抵消。

### 3.2 线性：多束光的贡献可以相加

如果两束入射光分别贡献 $L_1$ 和 $L_2$，总贡献应该是 $L_1 + L_2$。这也是渲染方程能写成积分的基础。

### 3.3 互易性 Helmholtz Reciprocity

$$
f_r(p, ω_i, ω_o) = f_r(p, ω_o, ω_i)
$$

直觉：把光源和相机交换位置，普通被动材质的反射规律应该一样。

大多数普通表面满足互易性，但有些特殊情况会破坏它，比如偏振材料、荧光材料、带磁光效应的材料等。GAMES101 里默认讨论普通被动材质。

### 3.4 能量守恒 Energy Conservation

固定一个入射方向，把反射到整个半球的能量加起来，不能超过入射能量：

$$
\int_\Omega^+ f_r(p, \omega_i, \omega_o)\,\cos\theta_o\,d\omega_o \le 1
$$

这条在 PBR 里特别重要。很多“看起来很酷”的 shader 如果把 diffuse、高光、clearcoat、sheen 直接硬加，很容易让材质反射出比入射更多的能量，结果就是物体像自己在发光。

一个实用判断：

```text
如果关掉所有 emission，场景仍然越弹越亮，大概率是材质或采样权重破坏了能量守恒。
```

## 4. 用 lobe 看材质：材质是在“分配方向”

BRDF 在方向空间里的形状常叫 **lobe**。你可以把它想成：一束光打到表面后，表面向各个方向喷出多少光。

<MaterialLobeStudio client:only='react' />

| 材质类型 | Lobe 形状 | 外观 | 采样直觉 |
|---|---|---|---|
| Diffuse | 宽而平 | 像纸、粉笔、墙 | 半球里很多方向都有贡献 |
| Glossy | 围绕镜面方向成团 | 粗糙塑料、抛光木头 | 应该多采高光方向 |
| Mirror | 几乎只有一个方向 | 理想镜子 | 不随机，直接走反射方向 |
| Glass | 反射和折射两个 delta 或窄 lobe | 玻璃、水晶 | 按 Fresnel 在反射和折射间选择 |
| Anisotropic | 沿某个切线方向拉长 | 拉丝金属、丝绸 | 采样要知道 tangent 方向 |

注意：lobe 宽并不代表能量更多。粗糙高光变宽以后，峰值通常会降低；否则总能量会爆掉。

## 5. Lambertian 漫反射：为什么是 albedo / π？

理想漫反射假设表面向所有出射方向看起来一样亮，也就是 BRDF 是常数。

为了满足能量守恒，Lambertian BRDF 写成：

$$
f_r = ρ / π
$$

其中 $ρ$ 是 diffuse albedo，表示总共反射多少比例的入射能量。

为什么要除以 π？因为半球上的 cosine 积分等于 π：

$$
\int_\Omega^+ \cos\theta\,d\omega = \pi
$$

如果你直接写 $f_r = ρ$，总反射能量会变成 $ρπ$，白墙可能反射出超过入射的能量。

### 在 shader 里怎么对应？

```glsl
vec3 diffuseBRDF = albedo / PI;
vec3 Lo = diffuseBRDF * Li * max(dot(N, L), 0.0);
```

这里容易混淆：

- `albedo / PI` 才是 Lambertian BRDF。
- `max(dot(N, L), 0.0)` 是入射照度的投影项。
- `Li` 是入射 radiance。

也就是说，Lambertian 不是“乘一个 NdotL 就完了”。真正的物理结构是：

```text
出射 radiance = BRDF × 入射 radiance × cosine 投影 × 采样权重
```

## 6. 镜面反射、折射与 delta 分布

理想镜面反射只有一个出射方向：

$$
ω_r = 2(n · ω_i)n - ω_i
$$

严格说，理想镜面 BRDF 不是普通连续函数，而是 **Dirac delta distribution**。它在唯一的镜面方向上有贡献，其它方向为 0。

这会直接改变路径追踪策略：

```text
if material is diffuse:
    randomly sample hemisphere directions

if material is perfect mirror:
    deterministically spawn reflected ray

if material is perfect glass:
    choose reflection or refraction using Fresnel
```

### 折射：Snell 定律

折射方向由 Snell 定律决定：

$$
η_i sinθ_i = η_t sinθ_t
$$

| 介质 | 折射率 η 约值 | 直观效果 |
|---|---:|---|
| 空气 | 1.0 | 参考介质 |
| 水 | 1.33 | 水中物体看起来偏移 |
| 玻璃 | 1.5 左右 | 明显折射与反射 |
| 钻石 | 2.4 左右 | 强折射、强色散、强反射 |

当光从高折射率介质射向低折射率介质，并且入射角足够大时，折射解不存在，所有能量都反射回去，这就是 **total internal reflection / 全反射**。

## 7. Fresnel：为什么掠射角总是更亮？

Fresnel 描述反射率随角度变化。一个非常重要的事实是：

> 几乎所有材质在掠射角都会更反光。

实时渲染常用 Schlick 近似：

$$
F(θ) = F_0 + (1 - F_0)(1 - cosθ)^5
$$

<FresnelMetalnessLab client:only='react' />

### 非金属与金属的本质区别

| 材质 | 正入射反射率 $F_0$ | 高光颜色 | diffuse 分量 | 例子 |
|---|---:|---|---|---|
| Dielectric 非金属 | 通常 0.02 到 0.08 | 接近白色 | 有 | 塑料、木头、陶瓷、水 |
| Conductor 金属 | 通常很高 | 带金属本身颜色 | 基本没有普通 diffuse | 金、铜、铝、铁 |

这也是 PBR 中 `metallic` 的物理含义：它不是简单“把材质变亮”，而是在非金属模型和金属模型之间切换能量分配方式。

### 为什么塑料边缘也会亮？

正面看塑料时，只有少量光发生镜面反射，所以你主要看到 diffuse albedo。到了掠射角，Fresnel 反射率迅速升高，于是边缘会出现明显反光。水面、地板、车漆、手机屏幕都能看到这个现象。

## 8. Microfacet：粗糙高光来自无数小镜子

现实表面即使肉眼看起来平，也有微小凹凸。Microfacet 模型把表面想象成大量微小镜面：

```text
宏观表面 normal = n
微表面 normal   = m
每个微表面都是小镜子
粗糙度决定这些小镜子的朝向分布
```

只有微表面法线接近 half vector 的那部分小镜子，才能把 $ω_i$ 方向的光反射到 $ω_o$：

$$
h = normalize(ω_i + ω_o)
$$

经典 microfacet BRDF：

$$
f_r(ω_i, ω_o) = D(h) F(ω_i, h) G(ω_i, ω_o, h) / 4(n · ω_i)(n · ω_o)
$$

<MicrofacetDFGExplorer client:only='react' />

| 项 | 名字 | 它在问什么 | 直观影响 |
|---|---|---|---|
| D | Normal Distribution Function | 有多少微表面朝向 half vector？ | 决定高光形状和宽度 |
| F | Fresnel Term | 当前角度反射率是多少？ | 掠射角增强，金属有色高光 |
| G | Geometry Term | 微表面互相遮挡多少？ | 粗糙表面暗化，掠射角遮蔽 |
| 分母 | Jacobian / 投影校正 | 从 half vector 分布转到出射方向 | 保证测度转换正确 |

### D：法线分布决定高光轮廓

常见 NDF：

| NDF | 特点 | 常见场景 |
|---|---|---|
| Beckmann | 高斯斜率分布，尾部较短 | 早期物理材质模型 |
| GGX / Trowbridge-Reitz | 长尾，高光拖尾明显 | 现代实时 PBR 常用 |
| Anisotropic GGX | x/y 粗糙度不同 | 拉丝金属、头发、织物 |

GGX 的长尾非常重要，因为现实中很多粗糙表面在高光外侧仍有一圈拖尾，不像 Phong 那样快速消失。

### F：Fresnel 决定角度相关反射率

F 项不是“额外加亮”，而是告诉你当前角度下有多少能量进入镜面反射通道。非金属 F0 小，金属 F0 大且带颜色。

### G：遮蔽与掩蔽

粗糙表面的小山小谷会相互挡住：

- **Masking**：观察方向上，一些微表面被挡住，看不到。
- **Shadowing**：入射方向上，一些微表面收不到光。

roughness 越大、视角越掠射，G 的影响越强。

## 9. 各向同性与各向异性：为什么 tangent 很重要？

如果材质绕法线旋转后外观不变，叫 **isotropic / 各向同性**。普通塑料、粗糙墙面通常可以这样近似。

如果材质外观依赖某个切线方向，叫 **anisotropic / 各向异性**。

<AnisotropicMaterialLab3D client:only='react' />

典型例子：

| 材质 | 为什么各向异性 | 视觉特征 |
|---|---|---|
| 拉丝金属 | 表面有统一刷痕 | 高光沿刷痕方向被拉长 |
| 丝绸 | 纤维方向明显 | 转动布料时明暗快速变化 |
| 头发 | 发丝是细长圆柱 | 沿发丝方向有多重高光 |
| CD / 光栅表面 | 微结构方向规则 | 彩虹色衍射效果 |

这解释了为什么很多渲染管线里不仅需要 normal，还需要 tangent 和 bitangent。TBN 矩阵不只是 normal map 的工具，也是在告诉各向异性 BRDF：表面“横向”和“纵向”分别在哪里。

```text
normal    决定表面朝向
 tangent  决定刷痕、纤维、拉伸高光方向
 bitangent 与 normal、tangent 一起形成局部坐标系
```

## 10. 测量 BRDF：真实材质可以直接采样出来

很多材质很难靠简单公式写出来，比如天鹅绒、织物、皮肤、氧化金属、多层车漆。另一条路线是直接测量。

<MeasuredBRDFCapture3D client:only='react' />

典型 BRDF 测量流程：

1. 把材质样本固定在仪器中心。
2. 改变光源方向 $ω_i$。
3. 改变相机方向 $ω_o$。
4. 记录每一对方向下的反射 radiance。
5. 存成高维表格、压缩表示或拟合成解析模型。

代表数据集是 **MERL BRDF Database**。它包含大量真实材质测量数据，常用于渲染论文和材质模型验证。

| 测量材质的优点 | 测量材质的难点 |
|---|---|
| 可以捕捉真实复杂外观 | 数据维度高，存储大 |
| 不需要手写所有物理细节 | 很难覆盖所有入射和出射方向 |
| 可用于校准 PBR 参数 | 插值和重要性采样不容易 |
| 适合做离线参考 | 艺术控制不如参数化模型方便 |

生产中常见做法是：

```text
测量数据 -> 作为真实参考
解析 PBR -> 作为实时可控模型
材质扫描 -> 拟合出 baseColor / roughness / metallic / normal 等贴图
```

## 11. 和实时 PBR 参数逐个对上

**Base Color**  
物理意义：非金属的 diffuse albedo；金属的 specular color（$ρ$ 或 $F_0$）  
常见误区：金属的 baseColor 不是漫反射颜色

**Metallic**  
物理意义：非金属和金属模型切换，控制 diffuse/specular 能量分配  
常见误区：不该用 0.5 做”脏金属”万能值

**Roughness**  
物理意义：微表面法线分布宽度（影响 D 和 G 项）  
常见误区：roughness 变大不是简单 blur 高光

**Specular / IOR**  
物理意义：非金属正入射反射率（Fresnel $F_0$）  
常见误区：普通塑料 $F_0$ 通常很低（0.04 左右）

**Normal Map**  
物理意义：改变局部法线，影响所有 dot product  
常见误区：normal map 不是颜色贴图，不能 sRGB 解码

**Anisotropy**  
物理意义：切线方向粗糙度差异（需要 tangent/bitangent）  
常见误区：没有 tangent 就不知道拉伸方向

**Transmission**  
物理意义：透射比例（BTDF/BSDF）  
常见误区：透明不等于没有反射（仍有 Fresnel）

**Emission**  
物理意义：自发光 $L_e$  
常见误区：emission 不是 BRDF 的一部分

**Clearcoat**  
物理意义：额外光滑表层（多层 BRDF）  
常见误区：直接相加要注意能量守恒

简化版 microfacet PBR 伪代码：

```glsl
vec3 H = normalize(V + L);
float NdotL = max(dot(N, L), 0.0);
float NdotV = max(dot(N, V), 0.0);
float VdotH = max(dot(V, H), 0.0);

vec3 F = fresnelSchlick(VdotH, F0);
float D = distributionGGX(N, H, roughness);
float G = geometrySmith(N, V, L, roughness);

vec3 specularBRDF = D * F * G / max(4.0 * NdotL * NdotV, 0.001);
vec3 diffuseBRDF = (1.0 - metallic) * albedo / PI;

vec3 Lo = (diffuseBRDF + specularBRDF) * Li * NdotL;
```

真实引擎还会加入 image based lighting、BRDF LUT、multiple scattering compensation、clearcoat、sheen、transmission 等，但底层仍是本节课的方向分配思想。

## 12. 写渲染器时最常见的材质 bug

### Bug 1：方向约定混乱

有的代码把 `ray.direction` 定义为从相机到表面，有的 BRDF 函数要求 `wo` 是从表面到相机。如果不统一，Fresnel、高光和 normal map 都会错。

建议在代码开头写清楚：

```text
All shading directions are defined as pointing away from the surface.
wi = direction from surface to light
wo = direction from surface to camera
```

### Bug 2：忘记除以 pdf

Monte Carlo 估计里，采样方向后必须除以该方向的概率密度：

```text
contribution = Li * BRDF * cosTheta / pdf
```

否则你改采样分布时，图像亮度也会跟着错误变化。

### Bug 3：Lambertian 少了 π

很多初学代码写成：

```glsl
vec3 diffuse = albedo * Li * NdotL;
```

这在艺术上也许能看，但物理上不是 Lambertian BRDF。正确的 BRDF 部分是 `albedo / PI`。

### Bug 4：把 normal / roughness 当 sRGB 读

normal、roughness、metallic 是数据，不是颜色。它们不应该做 sRGB 解码。否则 roughness 分布和法线方向都会被非线性扭曲。

### Bug 5：金属还有 diffuse

真实金属的光进入表面后很快被自由电子吸收，通常没有普通介质那种体内漫反射。PBR 里 metallic 为 1 时，diffuse 通道应该基本关闭。

## 13. 一句话串起整节课

```text
BRDF 告诉渲染器：光从 wi 来到表面点 p 后，有多少 radiance 会被分配到 wo。
```

所有概念都围绕这句话展开：

| 概念 | 一句话抓重点 |
|---|---|
| Appearance | 外观由几何、光照、材质、相机和显示共同决定 |
| BRDF | 入射 irradiance 到出射 radiance 的方向分布密度 |
| BSDF | 统一描述反射和透射 |
| Lambertian | 最简单漫反射，BRDF 为 $ρ / π$ |
| Mirror | delta 分布，只沿镜面方向有贡献 |
| Fresnel | 反射率随角度变化，掠射角增强 |
| Microfacet | 粗糙高光来自微小镜面的统计分布 |
| D / F / G | 法线分布、角度反射率、遮蔽掩蔽 |
| Anisotropy | 外观依赖 tangent 方向 |
| Measured BRDF | 用真实采样数据描述复杂材质 |
| PBR | 把这些物理概念压缩成可控参数 |

## 总结

第 17 课的核心，是把“材质颜色”升级成“方向上的能量分配规律”。

学完这一课后，PBR 参数、路径追踪采样、金属和玻璃、粗糙高光、Fresnel 边缘反光、normal map、各向异性和测量材质会连成一条线：**渲染不是给物体涂色，而是在模拟光如何与表面交换能量。**
