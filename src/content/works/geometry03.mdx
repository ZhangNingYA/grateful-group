## 01 / Mesh Operations 在解决什么问题？

> **核心问题：** 给定一个 mesh，我们为什么还要修改它？

Mesh 是显式几何的重要表示形式，但原始 mesh 不一定适合所有任务：

- **太粗糙**：低模看起来有棱角，需要 subdivision 变平滑。
- **太复杂**：百万面扫描模型放不进实时渲染，需要 simplification 减面。
- **质量太差**：skinny triangles、不规则 valence 会导致仿真不稳定，需要 regularization。

Mesh Operations 的三大方向：

| 操作 | 面数变化 | 目标 |
|------|----------|------|
| Subdivision | ↑ 增加 | 更平滑 |
| Simplification | ↓ 减少 | 更轻量 |
| Regularization | ≈ 可变 | 更健康 |

> 💡 **小结：** Mesh Operations 是对已有网格做"变换"——不是从零创建几何，而是改善已有几何的质量、复杂度或平滑度。

## 02 / Mesh Anatomy: 顶点、边、面与邻接关系

> **核心问题：** 为什么 mesh processing 不能只存顶点坐标？

Triangle Mesh 由两类信息组成：

- **Geometry 几何信息**：顶点位置、法线、UV 等。
- **Topology 拓扑信息**：哪些点构成边，哪些边构成面，哪些面相邻。

```
V = {v0, v1, v2, ...}       // 顶点位置
F = {(i0, i1, i2), ...}     // 三角形索引
```

关键概念：
- **Valence 度数**：一个顶点连接了多少条边。
- **Adjacency 邻接**：谁和谁相连。
- **Manifold 流形**：每条边最多被两个面共享。

> 💡 **小结：** 很多 mesh 操作不是只看孤立的点，而是依赖邻接关系。Mesh processing 经常同时修改 geometry 和 topology。

## 03 / Half-Edge Structure

> **核心问题：** 怎样快速找到一个边的相邻面、相邻点和相邻边？

Face list 对渲染足够简单，但对 mesh editing 不够方便。Half-edge 把每条边拆成两个方向相反的有向边，从而让邻接查询更高效。

```ts
type HalfEdge = {
  vertex: Vertex;    // 起始顶点
  twin: HalfEdge;    // 反方向的半边
  next: HalfEdge;    // 同一面内的下一条半边
  face: Face;        // 所属面
};
```

核心操作：
- `next` → 沿着当前 face 走
- `twin` → 跳到相邻 face
- `face` → 知道当前半边属于哪个面

<HalfEdgeStructureExplainer client:only="react" />

> 💡 **小结：** Half-edge 让我们能在 O(1) 时间内找到一条边的左右两个面、相邻顶点和后续边。这对 Edge Flip、Split、Collapse 等操作至关重要。

## 04 / Local Mesh Operations 局部操作

> **核心问题：** 复杂网格算法的基础局部操作是什么？

三种基本操作：

### Edge Split
在边上插入一个新顶点，原有相邻三角形被分裂。
- **用途**：增加局部细节。

### Edge Flip
对两个共享边的三角形，把对角线换成另一条。
- **用途**：改善三角形质量或调整连接。

### Edge Collapse
把一条边的两个端点合并成一个点，相邻三角形被移除或更新。
- **用途**：减少网格复杂度。

> 💡 **小结：** 这三种操作是 subdivision、simplification、remeshing 的底层工具。复杂算法 = 局部操作 + 选择策略。

## 05 / Subdivision 网格细分

> **核心问题：** 如何从一个粗糙的控制网格得到更平滑的表面？

Subdivision 的核心思想：
1. 增加新的顶点和面（split）
2. 根据邻居重新计算顶点位置（smooth）
3. 反复迭代，得到越来越平滑的表面

**关键洞察：** Subdivision 不是简单把每个三角形切开。真正产生光滑效果的是**顶点位置更新规则**。

<SubdivisionComparison3D client:only="react" />

> 💡 **小结：** Subdivision 的输入是 coarse control mesh，输出是更密更平滑的 mesh。它类似于 Bézier 曲线的思想——用少量控制点定义平滑形状。

**自测：** 为什么只 split triangle 但不平滑顶点，模型不一定会变得更光滑？

## 06 / Loop Subdivision

> **核心问题：** 三角网格如何通过 Loop Subdivision 变光滑？

**适用对象：** Triangle Mesh

**步骤：**
1. 每个三角形被分成 4 个小三角形
2. 每条旧边上生成一个**新边点 (odd vertex)**
3. 旧顶点根据一圈邻居重新定位 **(even vertex update)**
4. 重复操作，网格趋向更平滑

**新边点公式：**

$$
p_{new} = \frac{3}{8}(A+B) + \frac{1}{8}(C+D)
$$

其中 A、B 是边的两个端点，C、D 是共享这条边的两个三角形中相对的顶点。

**旧顶点更新公式：**

$$
p' = (1 - nu)\,p + u \sum_{i=1}^{n} p_i
$$

$$
u = \begin{cases} \frac{3}{16}, & n = 3 \\ \frac{3}{8n}, & n > 3 \end{cases}
$$

**通俗理解：** 新边点不是简单的中点，而是考虑了两侧三角形的"对面顶点"。旧顶点也会被邻居"拉"向平均位置。这两个规则共同保证了极限曲面的光滑性。

<LoopSubdivisionLab client:only="react" />

> 💡 **小结：** Loop Subdivision 的关键不是"切四块"，而是加权顶点更新。权重来自对极限曲面光滑性的数学分析。

**自测：** 在新边点公式中，为什么除了边的两个端点 A、B，还要考虑两侧三角形的相对顶点 C、D？

## 07 / Catmull-Clark Subdivision

> **核心问题：** 四边形网格如何通过 Catmull-Clark Subdivision 变光滑？

**适用对象：** Quad Mesh（也可推广到一般多边形网格）

**步骤：**
1. 对每个 face 计算 **face point**
2. 对每条 edge 计算 **edge point**
3. 对每个 old vertex 计算新位置
4. 重新连接成新的 quad mesh

**Face point：**

$$
F = \text{average}(\text{face vertices})
$$

**Edge point：**

$$
E = \text{average}(\text{edge endpoints and adjacent face points})
$$

**Vertex update（简化公式）：**

$$
V' = \frac{F + 2E + (n-3)V}{n}
$$

其中 $F$ 是相邻 face points 的平均，$E$ 是相邻 edge midpoints 的平均，$n$ 是顶点 valence。

<CatmullClarkSubdivisionLab client:only="react" />

> 💡 **小结：** Catmull-Clark 是许多建模软件中 subdivision surface 的核心。观察 cube 如何经过多次细分后趋向球形——这就是"控制网格 → 光滑曲面"的直觉。

## 08 / Mesh Simplification 网格简化

> **核心问题：** 如何减少 mesh 的面数，同时尽量保留外形？

Mesh Simplification 的目标：
- 减少存储和传输成本
- 提升渲染性能
- 生成 LOD（Level of Detail）
- 适配实时应用

**核心方法：Edge Collapse**
- 选择一条"代价最小"的边
- 把两个端点合并成一个新顶点
- 删除退化三角形
- 重复直到达到目标面数

<SimplificationEdgeCollapseLab client:only="react" />

> 💡 **小结：** 网格简化不是随机删除三角形，而是通过一系列精心选择的 edge collapse，在尽量保持形状的同时减少复杂度。

**自测：** 为什么简化算法不能简单随机删除三角形？

## 09 / Quadric Error Metrics / QEM

> **核心问题：** 如何判断 collapse 哪条边代价最小？

**核心直觉：** 一个顶点附近的表面可以由若干平面近似。如果 collapse 后的新顶点仍然接近这些平面，就说明它对局部形状破坏较小。

**平面方程：**

$$
ax + by + cz + d = 0
$$

**误差度量：**

$$
E(v) = \sum_i (a_i x + b_i y + c_i z + d_i)^2
$$

**齐次矩阵形式：**

$$
E(v) = v^T Q v
$$

**通俗理解：** QEM 为每个候选 collapse 位置计算"离周围平面有多远"。误差越小，说明 collapse 对形状破坏越小。优先执行误差最小的 edge collapse。

<QuadricErrorMetricsExplorer client:only="react" />

> 💡 **小结：** QEM 的核心不是复杂矩阵运算，而是"选一个让局部平面距离误差最小的新顶点位置"。每次 collapse 后，新顶点的 Q 矩阵 = 两个端点的 Q 矩阵相加。

**自测：** 为什么 midpoint 不一定是最佳 collapse 位置？拖动上方组件中的 v* 观察误差变化。

## 10 / Progressive Mesh 与 LOD

> **核心问题：** Mesh 简化是否可以形成连续的细节层级？

如果我们记录每一次 edge collapse 的信息（哪条边、新顶点位置），就可以得到从高模到低模的简化序列。反过来，通过 **vertex split** 可以逐步恢复细节。

**用途：**
- **Progressive transmission**：先传低模，再逐步加载细节
- **Level of Detail / LOD**：远处用低模，近处用高模
- **实时渲染优化**：根据距离和重要性动态调整

> 💡 **小结：** Mesh simplification 不只是静态压缩，也可以形成多层次细节。这是游戏引擎中 LOD 系统的理论基础。

**自测：** 游戏中远处山体为什么可以用更低面数的 mesh？

## 11 / Mesh Regularization / Remeshing

> **核心问题：** 如何让网格更"健康"？

Regularization 的目标不是改变整体形状，而是改善 mesh 的质量：

- 三角形更接近**等边**
- 边长更**均匀**
- 顶点 valence 更**规则**（理想值为 6）
- 避免 **skinny triangles**（极细长三角形）
- 保持边界和特征线

**为什么重要？**
- Skinny triangles 导致数值计算不稳定
- 不规则 valence 影响 subdivision 质量
- 不均匀采样导致纹理拉伸
- 好的网格是仿真、参数化、渲染的基础

**常用操作：**
- Edge Flip：改善局部连接
- Edge Split + Collapse：调整边长
- Laplacian Smoothing：平滑顶点位置

> 💡 **小结：** Regularization 关注的是"连接和采样是否健康"，而不是宏观形状。好的网格质量是后续所有算法的基础。

**自测：** 为什么 skinny triangle 对数值计算和渲染都不理想？

## 12 / Normals、Curvature 与视觉特征

> **核心问题：** Mesh operations 如何影响视觉质量？

即使几何位置不变，法线也会显著影响渲染结果：

- **Face normal**：每个面一个法线 → flat shading
- **Vertex normal**：顶点处平均法线 → smooth shading
- **Curvature 曲率**：描述表面弯曲程度

**关键原则：**
- 高曲率区域应该保留更多细节
- Feature edges（尖锐边）不应被随意平滑
- 简化时要考虑法线变化，不只是位置误差

<NormalsAndCurvatureViewer3D client:only="react" />

> 💡 **小结：** 切换 flat/smooth shading 时，几何完全没变——只是法线插值方式不同。这说明法线对视觉的影响巨大，mesh 操作必须考虑法线和曲率。

**自测：** 切换 flat shading 和 smooth shading 时，模型几何是否真的改变了？

## 13 / 总结：三类 Mesh Operations

### 对比表

| 操作类型 | 输入 | 输出 | 面数变化 | 目标 | 典型算法 |
|----------|------|------|----------|------|----------|
| Subdivision | 粗网格 | 更密更平滑的网格 | ↑ 增加 | 平滑、增加细节 | Loop, Catmull-Clark |
| Simplification | 复杂网格 | 更少面的近似网格 | ↓ 减少 | 降低成本、保持形状 | Edge Collapse, QEM |
| Regularization | 质量差的网格 | 更规则的网格 | ≈ 可变 | 改善质量 | Edge Flip, Smoothing |

### 学习总结

- Mesh 是显式几何最重要的表示之一
- Mesh Operations 是对 mesh 的**几何和拓扑**进行修改
- **Subdivision** 让网格更密更平滑（Loop → 三角形，Catmull-Clark → 四边形）
- **Simplification** 让网格更轻量（Edge Collapse + QEM 选择最优 collapse）
- **Regularization** 让网格质量更好（均匀边长、规则 valence）
- **Edge Split / Flip / Collapse** 是很多高级算法的基本积木
- **QEM** 的核心是用局部平面误差衡量简化代价
- 法线和曲率影响视觉质量，mesh 操作必须考虑这些因素
